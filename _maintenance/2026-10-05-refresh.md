The booking button uses `https://srijitseal.com/calendly`, which was tested in the browser and resolves to
`https://calendly.com/srijitseal-vy1g/30-mins-srijit`. The separate `/meet` Google Calendar redirect is unchanged.

The publication list combines the current 30 entries with VSA Explainer from the saved version.
Scholar's thesis and company conference abstract were not added to this article/preprint/chapter list.
InfoAlign stays, with the correct OpenReview paper link. PhenQSAR remains excluded.
SHOT-CCR now links to the MICCAI 2026 proceedings and author repository.
The Scholar baseline in `_data/scholar_baseline.json` records 1,027 total citations and individual paper counts,
verified on October 5, 2026. It is a manual snapshot, not an automatically refreshed Scholar feed.
The weekly workflow selects the highest of that baseline, the previously displayed count, and the new OpenAlex count.
OpenAlex replaces a Scholar count only when strictly higher. A subsequent lower or unavailable count does not reduce it.
Each displayed count retains its source, source URL, and observation date. Blank Scholar counts are unavailable, not zero.
The author total uses the same policy independently; it is not the sum of mixed-source paper counts.
Update the JSON baseline after a manual Scholar check. The workflow also runs when that file changes on main.
After a successful stats refresh, it explicitly requests a Pages rebuild because bot commits do not trigger one automatically.
This uses the repository-scoped Actions token with Pages write permission; no personal token is stored in the site.
